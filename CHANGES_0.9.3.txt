СтройИД 0.9.3 — сохранение при блокировке файлов Windows

По присланному журналу: прежние ошибки устранены, 69 модульных тестов Windows
пройдены. Сборка остановилась позднее при атомарной замене JSON истории: WinError 5.

Изменения:
- Атомарная замена повторяется при Windows-ошибках 5, 32 и 33 с ограниченной
  задержкой (суммарно около 2,12 секунды). Полный временный файл создаётся один
  раз; старый файл никогда не очищается для обхода блокировки.
- При постоянном отказе исходный файл сохраняется и операция возвращает ошибку.
  Ошибки диска, места или другие причины не повторяются автоматически.
- Очистка временного файла также учитывает кратковременную блокировку.
- Наблюдатель регистрирует только папки, а изменения карточек и документов
  определяет по метаданным файлов. Прямых подписок на заменяемые файлы нет.
- Сообщение об ошибке закрытия больше не перекрывается вторым общим окном.
  Подробная причина и несохранённый ввод остаются в основном интерфейсе.
- Команда меню «Сохранить сейчас» вызывает настоящее ручное сохранение.

Новые проверки: краткие и постоянные блокировки, очистка временных файлов,
сохранность исходника, наблюдение за папками и изменение файла на месте.
В Windows выполняется дополнительный тест с настоящим CreateFileW-дескриптором
без разрешения удаления. На Linux этот единственный тест пропускается.
GUI-проверка: 10 сохранений и закрытие с 22 искусственными WinError 5,
затем повторное открытие базы. Прежние проверки сохранены.

Запуск сборки: build_windows.bat. После успешных проверок: release\StroyID.exe.
В полном архиве включены установщик Python и все библиотеки.

На Windows дополнительно проверяются только метаданные значимых файлов раз
в три секунды, чтобы замечать изменение на месте без переименования файла.
Неизменённая база при этом не перечитывается и не хешируется. История и сборки
не входят в этот список. Отдельный тест проверяет обнаружение такой правки.
