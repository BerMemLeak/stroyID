СтройИД 0.9.0 — изменения

Изменения существующих карточек сохраняются кнопкой «Сохранить изменения»
или при закрытии программы. Ввод текста больше не пишет базу на каждый символ.
При переходе с несохранённой формы: Сохранить / Не сохранять / Остаться.
При ошибке сохранения окно остаётся открытым, введённые данные остаются.
Незавершённые формы создания не сохраняются; новая карточка появляется
только после нажатия кнопки создания. Переключение в другое окно не создаёт материал.

Изменения базы отслеживаются по событиям файловой системы. Неизменённые JSON
и документы не перечитываются и не хешируются многократно в простое.
Внешнее изменение не заменяет несохранённый ввод; при сохранении проверяются конфликты.

Материал внутри объекта по умолчанию объектный: собственные документы и JSON.
Материал вне объекта по умолчанию общий: один рабочий паспорт и ссылки из объектов.
Общий паспорт редактируется во всех местах использования без дополнительного предупреждения.
Объектный материал можно перенести в общий справочник. Для старых общих паспортов
предусмотрен выбор области использования; принадлежность не угадывается автоматически.

Разделы системы остаются сверху, повторяющиеся ссылки слева убраны.
Обзор объекта и поведение его вкладок не изменены по просьбе пользователя.
Место выполнения АОСР берётся из объекта автоматически; отдельное поле убрано.
Исправлена подпись «как в комплекте». Добавлен прежний значок дома для окна и EXE.
Сохранены корзина, независимые выполнения, шаблоны Word и 12 сценариев экспорта.
