# СтройИД

Настольная программа для исполнительной документации: объекты и выполнения,
АОСР, исполнительные схемы, ведомости объёмов, документы качества и сборка
итогового PDF. Рабочая база хранится в выбранной папке; для совместной работы
можно использовать локальную папку Яндекс Диска.

Актуальная версия находится в ветке **main**.

## Собрать и запустить

Скачайте исходники через **Code → Download ZIP** и распакуйте их в отдельную
папку. При первой сборке понадобится интернет для загрузки зависимостей.

| Компьютер | Что запустить в папке исходников | Готовое приложение |
| --- | --- | --- |
| Windows x64, Intel/AMD | `build_windows.bat` | `release/StroyID.exe` |
| macOS 13+, Apple Silicon | `setup_and_build_macos.command` | `dist-macos/StroyID.app` |

Скрипты подготавливают Python 3.12/3.13 и отдельное окружение, устанавливают
зависимости, запускают тесты, собирают приложение и проверяют его запуск.
После успешной сборки программа открывается автоматически.

**На Mac** скрипт можно запустить из Terminal в папке исходников:

```bash
bash setup_and_build_macos.command
```

Если откроется установщик Python, завершите установку и закройте Installer —
скрипт продолжит работу. При отсутствии Command Line Tools сначала завершите
их установку в системном окне. Результат — локальное приложение `.app`,
которое можно перенести в Applications. DMG не создаётся; аккаунт Apple
Developer не нужен. Параметр `--no-launch` отключает запуск после сборки.

**На Windows** для сборки без последующего запуска используйте PowerShell:

```powershell
.\build_windows.ps1 -NoLaunch
```

Готовый EXE можно перенести на другой Windows x64 без установки Python.

## Начать работу

1. При первом запуске выберите папку базы или создайте новую.
2. Создайте объект, выполнение и нужные инженерные системы.
3. Заполните участников и подписантов, добавьте акты и исходные документы.
4. Откройте «Сборка ИД», выберите состав и порядок документов, сформируйте PDF.

Карточки сохраняются автоматически после паузы ввода. Кнопка «Назад» ждёт
сохранения перед переходом. История карточки позволяет посмотреть прошлые
данные и восстановить нужную версию.

Для формирования PDF из **Word-шаблонов** нужен установленный и активированный
Microsoft Word. На Mac при первом экспорте разрешите программе управлять Word.
Для оформления схем загрузите шрифт **ISOCPEUR** в разделе шаблонов рамки.

В справочнике «Материалы и паспорта» доступны кнопки «Скачать шаблон Excel»
и «Импорт материалов из Excel». Одна строка — один материал; несколько документов
задаются группами столбцов «Документ 1», «Документ 2» и далее.

В «Сборке ИД» кнопка «Подготовить папку для печати» сохраняет отдельные PDF
по порядку сборки, пачки по формату и режиму печати и таблицу комплектации.
АОСР ограничен двумя страницами: при переполнении программа предлагает реестры
и после подтверждения повторяет проверку.

## Если сборка остановилась

Подробности находятся в папке `logs/`, итоговый отчёт —
`release/build-report.json`. При обращении об ошибке приложите свежий журнал
и укажите свою операционную систему.

## Для разработки

В активированном окружении с установленными `requirements-build.txt`:

```bash
python app.py
python -m unittest discover -s tests -v
python tests/smoke_qt.py
python tests/smoke_pdf.py
```

Полная проверка со сборкой: `python tools/build_release.py`.
В GitHub Actions отдельно проверяются Windows и macOS. Реальное преобразование
через Word на сервере без Office не выполняется; локальная Mac-сборка проверяет
его дополнительно, если Word установлен.

| Где искать | Содержимое |
| --- | --- |
| `app.py` | Запуск приложения и связь с интерфейсом |
| `ui/` | Интерфейс и встроенные шаблоны |
| `tools/` | Сборка и проверки готового приложения |
| `tests/` | Модульные тесты и проверки интерфейса |
| `docs/` | Руководство и справочник тегов |
