СтройИД 0.9.2 — исправление остановки Windows-сборки

Причина двух ошибок из журнала: путь карточки после чтения имел разделитель /,
а заново рассчитанный путь Windows — разделитель \. Программа ошибочно считала
карточку перемещённой и создавала лишнюю версию с прежними данными. Это приводило
к ложным конфликтам при объединении разных карточек и могло перекрыть внешние
изменения при сохранении другой карточки.

Теперь все пути карточек, события и прежний служебный список файлов приводятся
к единому формату. Имена и расположение рабочих папок из-за этого не меняются.

Добавлены четыре теста с сериализацией путей Windows на любой платформе:
- неизменённые карточки не получают новых версий;
- внешнее изменение JSON сохраняется при правке другой карточки;
- независимые изменения двух рабочих копий объединяются без конфликта;
- прежний список файлов с \ распознаёт отсутствие карточки и не восстанавливает
  внешне удалённый файл без явного действия пользователя.

Тесты, остановившие сборку версии 0.9.1, сохранены и не отключены.
Сборка: распакуйте полный ZIP в новую папку и запустите build_windows.bat.
Готовый файл: release\StroyID.exe. Базу при запуске выберите прежнюю.
