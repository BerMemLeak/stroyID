СтройИД 0.9.4 — полный пакет для Windows x64 (Intel/AMD)

1. Полностью распакуйте ZIP в отдельную папку, например C:\StroyID_0.9.
2. Запустите build_windows.bat. Python, Qt, pypdf и средства сборки уже
   включены в vendor. Докачивать библиотеки вручную не требуется.
3. После успешных проверок готовый одиночный файл: release\StroyID.exe.
   Его можно перенести на другой Windows x64 без Python и исходного кода.
4. При первом запуске выберите папку рабочей базы. Для обновления выберите
   прежнюю базу: приложение создаст снимок перед переносом её структуры.
5. Для совместной работы используйте локальную папку Яндекс Диска и включите
   хранение файлов на компьютере. Укажите своё имя в настройках приложения.

Этот архив содержит полный набор для сборки, а не заранее собранный Windows EXE.
Windows EXE создаётся и проверяется непосредственно на вашем Windows.
Для открытия Word-шаблонов и преобразования DOCX в PDF нужен установленный Word.
Встроенные формы и прикреплённые PDF собираются без Word.

Перед переносом базы дождитесь полной синхронизации Яндекс Диска, закройте
старую версию у всех коллег и откройте базу новой версией на одном ПК.
После синхронизации перейдите на новую версию на остальных компьютерах.
Старая и новая версии не должны одновременно менять одну базу.

Если сборка остановилась, отправьте logs\build-errors.txt или самый свежий
logs\build-*.txt. Дополнительные сведения: release\build-report.json.

Что изменилось: CHANGES_0.9.4.txt. Работа с базой и корзиной: FOLDER_STORAGE.txt.
Экспорт: EXPORT_SCENARIOS.txt. Шаблоны: WORD_TEMPLATES.txt.

Сохранение в версии 0.9
Редактируйте карточку, затем нажмите «Сохранить изменения». При переходе
выберите Сохранить / Не сохранять / Остаться. При закрытии программа сохраняет
изменения существующих карточек. Незавершённые формы создания отменяются.
Если запись не удалась, окно остаётся открытым: исправьте причину и повторите.
