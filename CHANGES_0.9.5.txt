СтройИД 0.9.5

Карточки сохраняются автоматически после паузы ввода. Переходы, удаление и
экспорт дожидаются записи. Ошибка записи сохраняет введённые данные.
Создание материалов, общих документов и схем остаётся явным действием.

Один документ качества можно связать с несколькими материалами разных
объектов и общей базы. Файл хранится один раз. Две необязательные даты:
начало и окончание действия. Прежние документы доступны без конвертации;
при редактировании их можно перевести в общий документ.

Добавлены поиск по материалу, производителю и номеру документа,
категории, множественный выбор и выбор всех найденных материалов.
Выполнение имеет начало и окончание; прежняя дата сохранена как начало.

Вкладки переносятся по ширине. Выполнения раскрываются до систем.
Дополнительные документы объекта вынесены в одну карточку общих разделов.
Убраны повторные команды создания акта и удаления системы из заголовка.
Инициалы вычисляются из полного ФИО.

Порядок разделов и документов экспорта меняется перетаскиванием;
доступно управление Alt + стрелка вверх/вниз на рукоятке.
Общая документация и ИД для эксплуатации имеют отдельные переключатели.
Компания-исполнитель и заказчик выбираются независимо от правил профиля.
Выбор для экспорта не меняет исходную карточку объекта и готовые файлы.

Логотип компании вставляется изображением в Word-титульник. Поддерживается
тег {{Логотип_Компании}}, а для шаблона без тега — размещение сверху справа.
Присланные титульник и реестр доступны в разделе шаблонов.
Удалены разделы шаблонов паспортов/сертификатов, организационных документов
и паспортов оборудования. Рамка схемы выбирается как HTML на уровне объекта
или профиля. В карточке схемы — предпросмотр и включение рамки, по умолчанию
для новой схемы включённое.

Рамка сверена с ГОСТ Р 21.101-2026, приложениями Е и Ж: форма 3,
185 × 55 мм, поля 20/5 мм. Исправлены графы подписантов и положение
инвентарных граф. «Листов» заполняется только на первом листе, согласно Е.1.
ISOCPEUR проверяется перед сборкой, доступна загрузка TTF/OTF.
Шрифт не распространяется вместе с приложением и не подменяется молча.
При его отсутствии рамку нужно отключить либо загрузить ISOCPEUR.

Пустая схема не создаётся при отмене. Счётчик связей учитывает акт-владельца.
Схемы можно перемещать в корзину. Отсутствующий PDF остаётся явной ошибкой
экспорта, чтобы готовый комплект не терял документы незаметно.

Исправлен разбор пакета Word-заданий в Windows PowerShell: каждое задание
содержит один исходный путь и один целевой путь. Сборочный spec использует
существующие файлы. Добавлены проверки хранения, интерфейса и Windows CI.


Рамка и штамп оформлены по образцу ВК1: увеличен шрифт, длинные названия
переносятся внутри ячеек. Количество листов и реквизиты приложения выводятся
на каждой странице. Чертёж вписывается между штампами без обрезки.
Проверяющий и нормоконтроль задаются в системе. Разработчик выбирается
явно для каждой схемы, без значения по умолчанию. Стадия наследуется из
системы с возможностью переопределения в схеме.
В штампе выводятся номер и название схемы, даты берутся из АОСР.
Общая схема включается отдельным экземпляром для каждого связанного АОСР.
Перед экспортом показывается предупреждение о незаполненных подписантах.

При блокировке release\StroyID.exe сборка запрашивает нормальное закрытие
именно этой запущенной копии и повторяет замену под прежним именем.
Принудительное завершение не используется; при постоянной блокировке
старый EXE и новая сборка в dist-onefile сохраняются.

Блок «Состав и порядок итогового PDF» расположен перед кнопками сборки
и показывает тот же отфильтрованный состав, что предпросмотр и экспорт.
Выключенные общая документация и эксплуатация, невыбранные выполнения
и системы скрываются из порядка. При повторном включении порядок сохраняется.
Исключённые разделы выбранного тома доступны отдельно для восстановления.
